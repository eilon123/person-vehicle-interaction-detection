# Implementation status and plan changes

Implemented: clip audit; timestamp-aware decoding; pretrained detection and
BoT-SORT tracking; pair-window proposals; local quantized video verification;
validated event JSON; uncertainty/raw-response artifacts; geometry ablation;
full-length H.264 annotation; frame/timestamp export checks; reference-based event
evaluation; proposal and negative-encounter KPI functions; dependency/model pins;
CLI commands, tests, and a brief write-up.

The final run is `outputs/final`, separate from earlier smoke tests. Its manifest
is authoritative for run completion. `artifact_metrics.json`, generated by
`tools/summarize_results.py`, measures output completion and timing, not semantic
accuracy. Never interpret the planned KPI targets as measured performance.

Changes made during development:

- Use source-sensitive detector resolution (640 for low-resolution inputs, up to
  the configured 960 otherwise). Upscaling the monochrome clip to 960 caused the
  main car to be missed; 640 recovered it in a direct detector check.
- Use Qwen2.5-VL-7B in 4-bit mode on the 8 GB GPU. The 3B smoke test confused
  actions and returned inconsistent schema fields. Larger-model results still
  require review and are not presumed correct.
- Pass sixteen samples as a video with temporal metadata, rather than unrelated
  images. Use a fixed expanded pair crop without a composite overview strip.
- Track all frames for visible annotation geometry rather than propagating sparse
  boxes through occlusions. Source frame count/presentation times are retained.
- Keep uncertain outputs separate and exclude them from confirmed event JSON.
  This can lower recall; they are not treated as correct negatives in evaluation.

Not yet completed from the broader plan:

- Adjudicated annotations and negative encounters for all eight clips. The included
  one-clip assistant-reviewed development reference is only a sanity check.
- Independent full-corpus semantic scoring, description review, and fresh-inference
  repeatability measurements. Cache replay is not proof of model determinism.
- A global VLM rescue scan for detector misses, dense action-boundary refinement,
  and reliable association of fragmented within-clip tracks.
- Public GitHub/shared-artifact publication; the repository is currently local.

These are explicit scope/validation gaps, not hidden successful checks. The
implementation can run on new clips without hardcoded event labels or clip IDs.
The reference files are not used by inference.
